## Train a model with our training API and SDK
Pick a small, concrete use case — structured JSON extraction, a classifier, a tone or format the base model keeps getting wrong — build a tiny dataset for it, and fine-tune. The point is to feel the whole loop: dataset in, job running, checkpoint out, addon deployed, call it, compare against the base model.
Do it once through the SDK and once through firectl if you have time. Note anywhere the experience is confusing — that feedback is genuinely useful to us, and you will only have fresh eyes once.
Starting points: fine-tuning docs · fine-tuning via API · Fireworks Python SDK · training recipes in the cookbook
